I'm a frontend developer based in South Jakarta with 3+ years of building React apps for telecom and enterprise clients. Right now I work on a 100+ page network performance dashboard for a national mobile operator, where I led the move from Create React App to Vite and the upgrade to React 18. Most of my days are spent on charts, maps, and making big datasets feel fast.

I also write backend code when the job needs it (Node.js, FastAPI, SQL Server), which makes life easier when working with API teams.

When I'm not coding I'm probably gaming. That's also where the Persona 5 look on my portfolio came from.
